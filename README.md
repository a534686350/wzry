# 强哥公益雷达 · 王者荣耀实时对局雷达（全套源码）

实时对局战术地图 / 英雄情报 / 房间共享的完整实现，**三套后端 + 两套网页 + 一个安卓客户端**，全部免授权、无卡密、无到期限制。

> 数据来源为客户端上报的对局帧（TCP/WS），服务端只做中转与渲染，不含游戏本体。

---

## 这套源码能干什么

- **实时战术地图**：峡谷底图 + 蓝红双方英雄位置、血量百分比、技能/大招冷却、资源与防御塔倒计时
- **英雄情报面板**：最多 10 条，阵营、血量、大招状态、技能剩余秒数
- **房间目录**：多个客户端共享对局，网页/APP 按房间号进入观战
- **多级子站**：母站一键部署子站，子站自动镜像母站房间（不用客户自己配采集端）
- **双内核自适应**：S44 老内核（10 字段纯数字帧）与 1.2.8 新内核（16~17 字段）自动识别互转
- **安卓悬浮窗**：免登录、免云后台，填服务器 IP 即连，悬浮在游戏上绘制

| 目录 | 是什么 | 运行环境 | 端口 | 适合 |
|---|---|---|---|---|
| **根目录**<br>`king-relay-lite.py` + `dist/` | **Python 中转服务** + 新版网页雷达（Vue 打包，战术地图/英雄情报双栏）+ 后台 | Python 3.6~3.12，零第三方依赖 | 8080 / 8888 / 9999 | **新部署首选**，要一键给客户开子站 |

| **03-网页雷达(S44+PHP)** | 老版 **观战网页**（单文件 `index.html` + layui）+ 原 PHP 卡密体系（**已改免卡密**） | Nginx + PHP | 走 `/ws` 反代 | 配 02 用，或要老版 UI |

三套互不冲突，可以只跑一套，也可以「Python 中转跑新版网页 + Java 后端跑老版网页」，各占不同端口。

```
┌──────────────────────── 方案 A（推荐，根目录） ────────────────────────┐
│  浏览器 ──8080──> king-relay-lite.py ──> dist/index（新版网页）        │
│  APP    ──8888──>        ↑                └─> /admin（Python 内置后台） │
│  采集端 ──9999──>        └── 房间数据 / 对局帧 / 上游镜像                │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────── 方案 B（02 + 03） ────────────────────────────┐
│  浏览器 ──443/80──> nginx ──/ws──> 127.0.0.1:8888（Java Netty）        │
│                        └── 静态文件：03-网页雷达/index.html             │
└──────────────────────────────────────────────────────────────────────┘
```

## 快速开始

### A. Python 中转（推荐，一条命令）

```bash
# 上传整个目录到服务器，例如 /root/radar
cd /root/radar
bash deploy/install.sh /www/wwwroot/king 8080 8888 9999
```

脚本自动：检查 python3 → 检查端口 → 拷文件 → 写 systemd 单元 `king-relay-lite` → 启动 → 校验 HTTP → 打印后台密码。

```
============================================
 systemd    : active
 网页 HTTP  : 200
 网页       : http://本机IP:8080/
 后台       : http://本机IP:8080/admin
 数据 WS    : 本机IP:8888   （APP 填这个）
 上报 TCP   : 本机IP:9999
============================================
```

> **云服务器安全组必须放行 8080 / 8888 / 9999 三个 TCP**，只改 firewalld/ufw 不够。

### B. Java 后端 + S44 网页

```bash
# 1) 起 Java 后端（监听 8888）
cd "02-雷达后端(Java)"
java -jar -Xmx1024M -Xms256M home-server-0.0.1-SNAPSHOT.jar
#   或 sed 's|DOMAIN|/www/wwwroot/radar|g' radar-ws.service > /etc/systemd/system/radar-ws.service
#      systemctl daemon-reload && systemctl enable --now radar-ws

# 2) 网页放到站点根目录
cp -r "03-网页雷达(S44+PHP)/"* /www/wwwroot/radar/

# 3) nginx 加 /ws 反代（片段见 02/nginx-site.conf.example，免卡密版删掉 auth_request 那行）
nginx -t && nginx -s reload
```

打开 `http://你的域名/` 直接进观战页（右上角显示「公益版 · 免卡密」）。

## 端口模型

| 端口 | 用途 | 谁连 |
|---|---|---|
| **8080** | 网页 / 后台 / `/deploy` / `/app.apk` / 网页用 WebSocket | 浏览器 |
| **8888** | 游戏数据 WebSocket（房间列表、对局帧） | APP、采集端、子站镜像 |
| **9999** | 客户端上报（裸 TCP） | 采集端 |
| 80 / 443 | nginx 反代 8080（可选，想用域名访问就配） | 浏览器 |

8888 收到普通 HTTP 会 **302 跳到 8080**，旧链接不会白屏。
APP 端端口写死 8888，服务端与客户端必须一致。

## 技术要点

| 主题 | 做法 |
|---|---|
| **免授权** | `LICENSE_OFF = True`，6 处校验短路（部署卡密、授权码、远程复查、下发配置、403 拦截、复查线程）；改回 `False` 即恢复原体系 |
| **双内核自适应** | S44（10 字段）与 1.2.8（16~17 字段）自动识别，坐标按 340 基准换算互转 |
| **老内核轮询** | S44 服务端只推一次，30ms 泵线程 ≈32fps 持续发 `web<ts>[==]房间` |
| **上游镜像** | 子站连母站 WS 同步房间列表，按需订阅对局帧，断线 3s 重连（退避至 30s） |
| **一键部署** | 后台填客户机 SSH（或 `/deploy` 自助页）→ 装 python3 → 上传 → 写 systemd → 起服务 → 验端口；三端口三层写死 |
| **Python 兼容** | 3.6~3.12：`asyncio.run` / `create_task` / `serve_forever` 三处按版本降级 |
| **前台去授权** | 原混淆包还原为可读源码，删除域名白名单校验、`/support`、`/purchase` 赞助页、「搭建同款」按钮 |
| **APP 去授权** | 云后台配置请求替换为内置本地配置，反代理检测恒通过；**无内置默认服务器**，只能填自己的 IP/域名，端口固定 8888 |

## 安卓客户端

`dist/app.apk`（也可从网页右下角「下载 APP」下载）。

1. 安装 → 授予**悬浮窗权限**（必须，否则不绘制）
2. 首页填 **服务器 IP 或域名**（不用带 `http://`，不用带端口），端口固定 8888
3. 点「点击选择房间」→ 选房间，或手填房间号 → 「连接并开启绘制」
4. 回桌面，悬浮层开始绘制；「悬浮设置」可调头像大小、顶栏透明度、兵线/野怪/防御塔开关

## 常见问题

**Q：APP 填了域名，网页能看但 APP「没拉到房间」？**
A：多半填的是**原厂域名**，不是你的服务器。`nslookup` 确认 A 记录指向自己的机器；原厂后端只认原厂客户端签名。详见 `使用文档.md` 5.5 节。

**Q：连上后一直显示「已连接 · 等待数据」？**
A：老内核（S44）是请求-响应模型，APP 需主动轮询才出帧。首次连接会先探测房间（HTTP → WS，最长约 15 秒），通过后自动转「实时绘制中」。

**Q：网页打开正常但房间列表一直是 0？**
A：房间列表只由采集端推 **TCP 9999** 填充，服务端不会自己抓。没有采集端时显示 0 是正常的，房间 60 秒无新数据自动消失。

**Q：8080 外网访问不了？**
A：云安全组没放行。8080 是最容易漏的那个；也可以配 nginx 用 80/443 反代。

**Q：怎么换地图底图？**
A：`dist/index/map.txt.png` 是底图，想用 S44 简化版就 `cp map_s44.png map.txt.png` 后重启。

**Q：数据存哪？**
A：全在 `data/`（`nodes.json` / `clients.json` / `stats.json` / `samples/`）。`nodes.json` 明文存子站 SSH 密码，注意保管。

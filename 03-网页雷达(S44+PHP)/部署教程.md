# 王者雷达卡密系统：宝塔从 0 部署教程

本项目由以下部分组成：

- `login.html`：卡密登录页；
- `index.html`：雷达页面；
- `api/`：PHP + MySQL 卡密、会话和后台接口；
- `admin/`：卡密管理后台；
- `home-server-0.0.1-SNAPSHOT.jar`：Java Netty 服务，提供 WebSocket `:8888/ws`，同时会监听原始 Socket `:9999`；
- `install.php`：网页安装器。首次访问网站根目录时会自动跳转到此页。

部署完成后的公网访问链路：

```text
浏览器 HTTPS
  ├─ /login.html、/index.html
  ├─ /api/*.php           → PHP-FPM → MySQL
  └─ /ws                  → Nginx 会话校验 → 127.0.0.1:8888 Java WebSocket
```

`8888` 与 `9999` 均不应直接开放到公网；浏览器只通过 HTTPS 同源的 `/ws` 连接 WebSocket。

## 1. 本次已修复的源码问题

| 位置 | 原问题 | 已修复结果 |
|---|---|---|
| `admin/index.php` | 引入了不存在的 `admin/db.php`，后台会直接报错 | 改为正确引入 `../api/db.php` |
| 卡密解封 | 已激活卡密解封后被重置为 `unused`，再次登录会重新计算有效期 | 解封时按激活时间和到期时间恢复为 `unused`、`active` 或 `expired`，不再续期 |
| 会话并发 | 超出会话上限时只删除一条旧会话，异常数据会继续超限 | 登录前精确删除足够数量的最旧会话，插入新会话后不会超限 |
| IP 绑定 | `bind_ip=true` 时，仅登录校验 IP，泄露的令牌可在其他 IP 验证 | 每次 `verify` 和 WebSocket 握手均校验绑定 IP |
| 客户端 IP | 无条件信任 `X-Forwarded-For`，可被请求伪造 | 仅当 `REMOTE_ADDR` 位于 `trusted_proxies` 时才读取代理头 |
| 后台安全 | 明文比较密码、登录后不更新 Session ID、表单没有 CSRF 校验 | 支持 `password_hash`、登录后更新 Session ID，所有后台写操作和退出均有 CSRF 校验；超级密码可重设后台密码并使旧后台会话失效 |
| HTTPS WebSocket | HTTPS 页面会直连 `wss://域名:8888/ws`，但 Java 服务未配置 TLS | 标准 HTTP/HTTPS 访问自动改用同源 `/ws`，由 Nginx 反向代理到本机 Java 服务 |
| WebSocket 鉴权 | Java 服务端口直接开放时可绕过前端卡密页 | 登录后写入 HttpOnly 会话 Cookie；Nginx 在 `/ws` 转发前调用 `api/ws-auth.php` 校验。配合防火墙关闭 8888/9999 |
| 数据库初始化 | SQL 与 CLI 工具固定使用 `radar_auth` 数据库名 | SQL 仅保留表结构；安装器和 CLI 工具使用配置中的数据库名 |
| 安装流程 | 需要手动改配置、导入 SQL | 新增根目录 `install.php`，填写数据库名、用户名、密码、后台密码和超级密码后自动写配置、建表、锁定安装器 |
| `.user.ini` | 写死了旧服务器目录的 `open_basedir` | 移除硬编码目录，改为由宝塔按实际站点配置 |
| `index.html` 英雄 ID 列表 | 数组中缺失逗号导致整段 JavaScript 语法错误；随后又强制截断到 129 条 | 修正语法并保留全部配置的英雄 ID，不再按过期固定数量截断 |

> 新建数据库后没有预置测试卡密。请在 `/admin/` 中生成正式卡密。

## 2. 部署前准备

### 2.1 域名和服务器

1. 准备一台 Linux 服务器，建议 Ubuntu 22.04+/Debian 12+/AlmaLinux 9+/Rocky Linux 9+。
2. 将域名的 `A` 记录解析到服务器公网 IPv4。
3. 准备 SSH 登录方式和 `root` 或 sudo 权限。
4. 在云厂商安全组中准备放行：
   - `22/TCP`：SSH，只允许自己的固定 IP；
   - 宝塔安装后终端显示的面板端口，只允许自己的固定 IP；
   - `80/TCP`、`443/TCP`：网站访问。

不要在安全组中放行 `3306`、`8888`、`9999`。MySQL、Java WebSocket 与原始 Socket 均只供服务器内部使用。

### 2.2 上传包内应保留的文件

上传后网站根目录应包含：

```text
/www/wwwroot/DOMAIN/
├── index.php                     # 首次访问跳转 /install.php；安装后跳转 /login.html
├── install.php                   # 网页安装器
├── login.html
├── index.html
├── map.png
├── home-server-0.0.1-SNAPSHOT.jar
├── api/
├── admin/
├── database/init.sql
├── nginx/site.conf.example
├── deploy/radar-ws.service
└── storage/                      # 安装锁与运行时文件；禁止公网访问
```

## 3. 从纯净服务器安装宝塔

通过 SSH 登录服务器后，执行宝塔官方安装脚本：

```bash
if [ -f /usr/bin/curl ];then curl -sSO https://download.bt.cn/install/install_panel.sh;else wget -O install_panel.sh https://download.bt.cn/install/install_panel.sh;fi;bash install_panel.sh docscenter
```

安装程序询问是否安装到 `/www` 时输入 `y`。安装完成后，终端会显示宝塔面板地址、端口、用户名和密码。

1. 在云安全组和服务器防火墙中，仅向自己的 IP 放行终端显示的面板端口。
2. 浏览器打开终端输出的完整面板地址并登录。
3. 进入 **面板设置**，修改面板登录密码；将面板端口改为高位随机端口后，先在安全组与防火墙放行新端口，再保存设置。

## 4. 在宝塔安装运行环境

### 4.1 安装 LNMP 组件

进入 **软件商店 → 运行环境**，安装：

| 软件 | 建议版本 | 用途 |
|---|---:|---|
| Nginx | 当前稳定版本 | 网站与 WebSocket 反向代理 |
| MySQL | 8.0 或 5.7 | 卡密、会话数据 |
| PHP | 8.2；8.1 也可 | PHP 接口与后台 |
| phpMyAdmin | 可选 | 图形化查看数据库 |

PHP 8.1/8.2 均能运行本项目。站点运行 PHP 必须启用 `pdo_mysql`；推荐同时启用 `openssl`、`mbstring`、`fileinfo`。

在 **软件商店 → 已安装 → PHP 8.2 → 扩展** 检查：

```text
pdo_mysql   已安装
mysqli      已安装
openssl     已安装
mbstring    建议安装
fileinfo    建议安装
```

### 4.2 安装 Java 17

在宝塔 **终端** 或 SSH 中执行其中一种命令：

**Ubuntu / Debian：**

```bash
apt-get update
apt-get install -y openjdk-17-jre-headless
java -version
```

**AlmaLinux / Rocky Linux / CentOS Stream：**

```bash
dnf install -y java-17-openjdk-headless
java -version
```

输出中出现 `17` 即可。该 JAR 的编译目标为 Java 8，使用 Java 17 可以直接运行。

## 5. 创建 PHP 网站与数据库

### 5.1 创建站点

在宝塔中进入 **网站 → PHP 项目 → 添加站点**：

| 字段 | 填写内容 |
|---|---|
| 域名 | `example.com` 与 `www.example.com`；没有域名时可先填服务器 IP 测试 |
| 根目录 | `/www/wwwroot/example.com` |
| PHP 版本 | `PHP-8.2` |
| 数据库 | 勾选创建数据库，或稍后手动创建 |
| FTP | 按需，不需要可关闭 |

创建成功后，记录站点根目录。下文用 `DOMAIN` 指代域名、用 `/www/wwwroot/DOMAIN` 指代根目录。

### 5.2 创建数据库

若创建站点时没有同时创建数据库，进入 **数据库 → MySQL → 添加数据库**，填写：

```text
数据库名：radar_auth               # 可自定义，例如 domain_radar
用户名：radar_user                 # 可自定义
密码：使用随机强密码并保存
访问权限：本地服务器
编码：utf8mb4
```

安装器会连接这个已创建的数据库并自动建表，因此不要手动执行旧版带 `CREATE DATABASE` 的 SQL。

## 6. 上传源码、设置文件权限、运行网页安装器

### 6.1 上传

在宝塔 **文件** 中进入 `/www/wwwroot/DOMAIN/`，上传本项目所有文件并解压到根目录。上传完成后确认不存在多包一层目录的问题，例如错误结构：

```text
/www/wwwroot/DOMAIN/S44王者纯净带卡密登录/index.php
```

正确结构必须是：

```text
/www/wwwroot/DOMAIN/index.php
```

### 6.2 设置所有者和权限

在 SSH/宝塔终端执行，将 `DOMAIN` 改为真实站点目录：

```bash
chown -R www:www /www/wwwroot/DOMAIN
find /www/wwwroot/DOMAIN -type d -exec chmod 755 {} \;
find /www/wwwroot/DOMAIN -type f -exec chmod 644 {} \;
chmod 755 /www/wwwroot/DOMAIN
```

`api/config.php` 会由安装器生成。安装器需要 `api/` 与 `storage/` 对运行用户 `www` 可写；上面的所有者设置已满足这一点。

### 6.3 打开安装页

首次直接访问：

```text
http://DOMAIN/
```

会自动跳转：

```text
http://DOMAIN/install.php
```

填写：

| 字段 | 填写值 |
|---|---|
| 数据库名 | 宝塔数据库中创建的数据库名 |
| 数据库用户名 | 宝塔数据库中创建的用户名 |
| 数据库密码 | 对应数据库密码 |
| 后台管理密码 | 至少 10 位的强密码；用于 `/admin/` |
| 超级密码 | 至少 10 位，且必须与后台管理密码不同；仅用于忘记后台密码时的身份验证 |
| 数据库主机 | 本机 MySQL 保持 `127.0.0.1` |
| 首登后绑定卡密 IP | 用户 IP 固定时可勾选；移动网络用户建议不勾选 |

点击 **开始安装** 后，安装器会：

1. 连接输入的数据库；
2. 导入 `database/init.sql` 的两张表；
3. 生成 `api/config.php`；
4. 将后台密码和超级密码以 `password_hash` 哈希方式写入配置；
5. 创建 `storage/install.lock` 锁定安装器，阻止重复覆盖线上配置。

成功后先打开：

```text
http://DOMAIN/admin/
```

使用刚设置的后台管理密码登录，生成一张测试卡密。再打开：

```text
http://DOMAIN/login.html
```

输入卡密验证 PHP + MySQL 登录功能。

### 6.4 忘记后台密码

后台登录页底部有 **忘记后台密码？** 链接，也可以直接访问：

```text
http://DOMAIN/admin/?forgot=1
```

依次输入部署安装时设置的**超级密码**、新后台密码和确认密码，点击 **验证并重设密码**。新后台密码至少 10 位，且不能与超级密码相同。重设成功后，所有已登录的后台会话会立即失效，使用新后台密码重新登录即可。

超级密码和后台密码都只保存为哈希，`api/config.php` 中不会显示明文。

### 6.5 已安装站点补充超级密码

旧站点在 `storage/install.lock` 已存在时不会再次显示安装表单。上传本项目新版的以下文件到服务器同名目录（**不要用源码中的 `api/config.php` 覆盖线上正在使用的配置**）：

```text
admin/index.php
install.php
scripts/set-super-password.php
```

在宝塔终端执行，其中 `DOMAIN` 替换为站点目录名：

```bash
SITE="/www/wwwroot/DOMAIN"
chown -R www:www "$SITE/api" "$SITE/admin" "$SITE/scripts"
chmod 775 "$SITE/api"
/www/server/php/82/bin/php "$SITE/scripts/set-super-password.php"
```

按两次提示输入新的超级密码。完成后访问 `/admin/?forgot=1`，用该超级密码重设后台登录密码。

## 7. 配置 Nginx：保护文件并代理 `/ws`

这是 HTTPS 和卡密保护 WebSocket 的关键步骤。

### 7.1 确认 PHP-FPM 套接字

在终端执行：

```bash
ls -1 /tmp/php-cgi-*.sock
```

例如输出：

```text
/tmp/php-cgi-82.sock
```

### 7.2 复制配置片段

进入 **网站 → DOMAIN → 设置 → 配置文件**，在该站点的 `server { ... }` 内、现有 PHP 规则之前，粘贴下列内容。将 `php-cgi-82.sock` 替换为上一步实际输出的文件名：

```nginx
location ^~ /database/ { return 404; }
location ^~ /scripts/  { return 404; }
location ^~ /storage/  { return 404; }
location = /api/config.php         { return 404; }
location = /api/config.example.php { return 404; }
location = /api/db.php             { return 404; }

location = /api/ws-auth.php {
    internal;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_pass unix:/tmp/php-cgi-82.sock;
}

location /ws {
    auth_request /api/ws-auth.php;

    proxy_pass http://127.0.0.1:8888;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
    proxy_buffering off;
}
```

同一份可复制的内容也保存在：

```text
/www/wwwroot/DOMAIN/nginx/site.conf.example
```

保存前点击宝塔页面的 **配置检查**；通过后保存并重载 Nginx。

### 7.3 首页和防跨站

在 **网站 → DOMAIN → 设置 → 默认文档** 中确保顺序包含：

```text
index.php
login.html
index.html
```

项目根目录的 `index.php` 会在未安装时跳转 `/install.php`，安装完成后跳转 `/login.html`。

在 **网站 → DOMAIN → 设置 → 防跨站攻击(open_basedir)** 中：

- 开启时，将本站根目录 `/www/wwwroot/DOMAIN/` 加入允许路径；
- 如安装器或 PHP 日志提示文件访问被拦截，可临时关闭、完成安装后按实际路径重新启用；
- 不要恢复旧 `.user.ini` 中其他服务器的硬编码路径。

## 8. 将 Java WebSocket 服务设为开机自启

### 8.1 创建 systemd 服务

本项目提供模板：

```text
/www/wwwroot/DOMAIN/deploy/radar-ws.service
```

执行下列命令，将两处 `DOMAIN` 替换为真实根目录中的目录名：

```bash
sed 's#DOMAIN#example.com#g' /www/wwwroot/example.com/deploy/radar-ws.service \
  > /etc/systemd/system/radar-ws.service

systemctl daemon-reload
systemctl enable --now radar-ws
systemctl status radar-ws --no-pager
```

正常时状态应为：

```text
Active: active (running)
```

查看实时日志：

```bash
journalctl -u radar-ws -f
```

重启服务：

```bash
systemctl restart radar-ws
```

### 8.2 检查监听端口

```bash
ss -lntp | grep -E ':(8888|9999)\b'
```

JAR 正常启动时能看到 `8888` 和 `9999` 监听。Nginx 使用本机 `127.0.0.1:8888` 转发 `/ws`。

## 9. 防火墙与 HTTPS

### 9.1 防火墙规则

进入宝塔 **安全 → 系统防火墙 → 添加端口规则**：

| 端口 | 协议 | 规则 |
|---:|---|---|
| `80` | TCP | 允许所有来源 |
| `443` | TCP | 允许所有来源 |
| 面板端口 | TCP | 仅允许自己的管理 IP |
| `22` | TCP | 仅允许自己的管理 IP |
| `3306` | TCP | 不添加公网允许规则 |
| `8888` | TCP | 不添加公网允许规则 |
| `9999` | TCP | 不添加公网允许规则 |

云厂商安全组应使用相同策略：只放行 `80`、`443` 和受限来源的 SSH/宝塔面板端口。

### 9.2 申请证书并强制 HTTPS

在宝塔 **网站 → DOMAIN → 设置 → SSL**：

1. 选择 Let's Encrypt 或 LiteSSL；
2. 选择域名并申请证书；
3. 证书部署成功后开启 **强制 HTTPS**；
4. 访问 `https://DOMAIN/login.html`。

启用 HTTPS 后，前端会使用：

```text
wss://DOMAIN/ws
```

TLS 由 Nginx 终止，再由 Nginx 以本地 `ws://127.0.0.1:8888/ws` 转发给 Java，因此 JAR 不需要单独配置证书。

## 10. 上线验证清单

### 10.1 PHP 语法检查

在服务器中按实际 PHP 版本运行：

```bash
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/api/db.php
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/api/login.php
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/api/verify.php
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/api/logout.php
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/api/ws-auth.php
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/admin/index.php
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/install.php
```

每条均应返回：

```text
No syntax errors detected
```

### 10.2 浏览器验证

1. 访问 `https://DOMAIN/`，应跳转到 `login.html`。
2. 访问 `https://DOMAIN/admin/`，应能使用安装时设置的后台密码登录。
3. 在后台生成卡密。
4. 用该卡密在 `login.html` 登录，应跳转 `index.html`。
5. 按 `F12 → Network → WS`，连接地址应为 `/ws`，状态应为 `101 Switching Protocols`。
6. 再用无痕窗口访问 `/ws`：因为没有登录 Cookie，Nginx 应拒绝 WebSocket 握手。
7. 在后台封禁已登录卡密后刷新雷达页，应被带回登录页。
8. 解封已激活卡密后，后台显示的到期时间不应变化。

### 10.3 数据库验证

在宝塔 phpMyAdmin 中选择安装时填写的数据库，确认存在：

```text
card_keys
sessions
```

后台生成卡密后应写入 `card_keys`；登录后应在 `sessions` 中出现一个 64 位 token 记录。

## 11. 常见问题

### 安装页提示数据库连接、建表或写入配置失败

按顺序检查：

```bash
# 查看 PHP-FPM 错误日志，路径按实际 PHP 版本调整
tail -n 100 /www/wwwlogs/DOMAIN.error.log

# 检查运行用户对项目目录的访问权限
namei -l /www/wwwroot/DOMAIN/api/config.php
```

确认数据库的访问权限选择了 **本地服务器**，数据库名、用户名、密码完全一致，且 PHP 已启用 `pdo_mysql`。

### 管理后台空白、500 或数据库错误

```bash
/www/server/php/82/bin/php -l /www/wwwroot/DOMAIN/admin/index.php
systemctl restart php-fpm-82 2>/dev/null || true
```

随后查看宝塔 **网站 → 日志**。本版本已修正后台错误引用 `admin/db.php` 的问题。

### HTTPS 后 WebSocket 连接失败或显示 502/401

依次执行：

```bash
systemctl status radar-ws --no-pager
journalctl -u radar-ws -n 100 --no-pager
nginx -t
systemctl reload nginx
```

再检查：

1. Nginx 中 `/ws` 的 `proxy_pass` 是否仍是 `http://127.0.0.1:8888`；
2. `api/ws-auth.php` 的 `internal` 位置块是否使用了正确 PHP-FPM socket；
3. 已重新通过 `login.html` 登录，以获得 `radar_ws_token` HttpOnly Cookie；
4. 云安全组和宝塔防火墙没有向公网开放 `8888`、`9999`。

### 切换了服务器或域名后 IP 绑定导致登录失败

如果安装时勾选了 `bind_ip`，首次登录后的卡密绑定了客户端 IP。移动网络、代理或网络切换会更换 IP。可在后台封禁并解封该卡密，或在数据库中明确清理该卡密绑定和会话后重新激活；日常用户网络不固定时，安装阶段不要勾选该项。

### 需要重新安装

安装器通过 `storage/install.lock` 防止线上站点被重复覆盖。重新安装前先备份数据库与 `api/config.php`，确认不再需要现有数据后，再删除安装锁并重新访问 `/install.php`。

## 12. 日常维护

1. 在宝塔 **计划任务** 中设置 MySQL 数据库每日备份，保留至少 7 天。
2. 每次更新源码前备份：

   ```bash
   cp /www/wwwroot/DOMAIN/api/config.php /www/backup/radar-config-$(date +%F).php
   ```

3. 更新后依次运行 PHP 语法检查、`nginx -t`、`systemctl restart radar-ws`。
4. 后台密码和超级密码均使用哈希保存；日常修改后台密码请使用后台登录页的 **忘记后台密码？** 流程。仅需初始化或更换超级密码时，运行 `scripts/set-super-password.php`。
5. 保持 `3306`、`8888`、`9999` 不对公网开放；对外仅提供 `80/443`。
